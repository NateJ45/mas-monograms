MAS Monograms: my colors

CMYK numbers are approximate (worked out from the color code with the plain textbook formula).
For printing, ask the printer to match the color code (hex) or show you a printed proof.

Linen
  Color code (hex): #F4EEE3
  RGB: 244, 238, 227
  CMYK (approximate): C 0  M 2  Y 7  K 4
  Use it for: Your main background: a warm, soft off-white. Most of your website sits on it.

Paper
  Color code (hex): #FBF8F1
  RGB: 251, 248, 241
  CMYK (approximate): C 0  M 1  Y 4  K 2
  Use it for: Cards and boxes that sit on Linen. A touch brighter.

Midnight
  Color code (hex): #0F1B2D
  RGB: 15, 27, 45
  CMYK (approximate): C 67  M 40  Y 0  K 82
  Use it for: The deep dark blue behind the gold logo. Use it for dark backgrounds.

Heritage Indigo
  Color code (hex): #28486B
  RGB: 40, 72, 107
  CMYK (approximate): C 63  M 33  Y 0  K 58
  Use it for: The brand blue: the hoops in your logo, links and calm dark bands.

Heirloom Ink
  Color code (hex): #26312E
  RGB: 38, 49, 46
  CMYK (approximate): C 22  M 0  Y 6  K 81
  Use it for: Words on light backgrounds. A deep, warm near-black.

Claret
  Color code (hex): #8C3A2E
  RGB: 140, 58, 46
  CMYK (approximate): C 0  M 59  Y 67  K 45
  Use it for: The button that matters most, like Request a Quote. Use it once per design so it stays special. Never in the logo.

Brass

  CMYK (approximate): C 0  M 31  Y 73  K 49

Gold thread

  CMYK (approximate): C 0  M 18  Y 56  K 15

  CMYK (approximate): C 0  M 1  Y 7  K 11

The gold thread
