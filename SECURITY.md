# Security policy

## Supported versions

Only the `main` branch is supported. It is the version deployed at [mas-monograms.com](https://mas-monograms.com).

## Reporting a vulnerability

Please report security issues privately by email to **nathan@nixoncreativestudio.com**. Do not open a public GitHub issue for a vulnerability.

Include what you found, the steps to reproduce it, and the affected URL or file. You can expect an acknowledgement within a few days. Secrets for this project (email, Turnstile and CMS tokens) live in Cloudflare Worker secrets and are never committed to the repo.
